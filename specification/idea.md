# Idea (raw)

Geração de uma aplicação que terá como frontend uma página em React que será
hospedada no Github Pages, e o banco de dados no Firebase. Esta aplicação vai
gerenciar os mais de 600 livros físicos da minha biblioteca pessoal.

## Notas brutas
- Frontend: React
- Hospedagem: GitHub Pages
- Banco de dados: Firebase
- Escopo: gerenciar 600+ livros físicos de uma biblioteca pessoal
